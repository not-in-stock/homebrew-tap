# homebrew-tap

Homebrew tap by [not-in-stock](https://github.com/not-in-stock). Contains personal projects and third-party macOS apps not available in the official Homebrew registry.

## Install

```bash
brew tap not-in-stock/tap
```

## Casks

| Cask | Description |
| :--- | :---------- |
| [kanata-bar](https://github.com/not-in-stock/kanata-bar) | macOS menu bar app for kanata keyboard remapper |
| [naya-flow](https://github.com/NayaTech/NayaFlow-releases) | Keyboard companion app by NayaTech |

### kanata-bar

```bash
brew install not-in-stock/tap/kanata-bar
```

### naya-flow

```bash
brew install not-in-stock/tap/naya-flow
```
